# CSS Skew-Active Navbar

A modern **Skew-Active Navbar** built using pure HTML5 and CSS3 for Gaming Hub layouts. Navigation items skew smoothly on hover, creating an energetic interaction while remaining lightweight, responsive, and accessible.

---

## ✨ Features

- Pure HTML5 & CSS3
- Skew-active hover animation
- Gaming-inspired navigation
- Fully responsive
- CSS Custom Properties
- Lightweight and performant
- Accessible semantic HTML
- Keyboard focus support
- `prefers-reduced-motion` support
- No JavaScript required

## 🚀 Usage

1. Copy the component into your project.
2. Link the stylesheet:

```html

```

3. Open `demo.html` in your browser.
