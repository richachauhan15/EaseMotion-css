# CSS Reading Mode Typography

A responsive typography system designed for comfortable long-form reading.

## Features

- Pure CSS implementation
- Optimized reading width
- Comfortable line height
- Responsive typography
- Clear heading hierarchy
- Article metadata styling
- Styled blockquote
- Soft reading-focused color palette
- Mobile responsive layout
- Reduced-motion support
- No JavaScript required

## Files

- `demo.html` — Reading mode demonstration
- `style.css` — Typography and layout styles
- `README.md` — Documentation

## Usage

Copy the article structure and include `style.css` in your project.

The component can be adapted for blogs, documentation pages, articles,
documentation portals, and other long-form content.

## Accessibility

The example uses semantic article, header, footer, heading, time, and
blockquote elements. Text maintains a readable contrast and the layout
adapts to smaller screens.
