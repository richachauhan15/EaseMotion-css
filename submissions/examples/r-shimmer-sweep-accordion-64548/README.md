# CSS Shimmer-Sweep Accordion

A minimalist, responsive accordion featuring a subtle CSS-only shimmer sweep interaction.

## Features

- Pure HTML and CSS
- No JavaScript or external dependencies
- Native `<details>` and `<summary>` accessibility
- Shimmer-sweep hover and focus effect
- Smooth open-state transitions
- Responsive desktop, tablet, and mobile layout
- Keyboard accessible
- `prefers-reduced-motion` support
- Customizable CSS variables
